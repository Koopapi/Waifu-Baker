# Entrevista — Spec 017, armado de cartas por capas

Contexto: al aprobar la spec 016, el dueño decidió que todas las cartas serán cartas por capas con el sistema de Bruno.
Aclaró después que el proyecto aún no está en producción y que él y Bruno arman cada carta a mano antes de lanzar una
colección, con la chica recortada sin fondo como imagen central.

1. **Cartas existentes** (23 oct 2026): eran material de prueba; no hay conversión automática ni transición.
2. **Cómo nace una carta** (23 oct 2026): subir la imagen de la chica crea la carta por capas; también desde varias
   capas.
3. **Orden** (23 oct 2026): primero el armado en el panel (017) y luego que se vean en toda la web (018).
4. **Fondos** (23 oct 2026): las dos cosas: biblioteca por colección y fondo propio por carta cuando haga falta.
5. **Recorte** (23 oct 2026): se hace fuera del panel (Photoshop u otra herramienta); el panel recibe el PNG recortado.
6. **Encuadre** (23 oct 2026): mover, escalar y girar cada capa.
7. **Publicar** (23 oct 2026): no se publica una colección con cartas sin armar (personaje y fondo).
