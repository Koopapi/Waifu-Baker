# Spec 018 — Prueba en un teléfono real

La constitución (principio 9) pide 60 fps en Pixel 6a e iPhone 12 y el permiso del giroscopio solo se puede probar en un
teléfono de verdad. La firma el dueño tras probarlo.

Con la demo abierta en el teléfono (misma red Wi-Fi que la computadora: `http://<ip-de-la-mac>:3300`):

| # | Qué hacer | Qué debe pasar | ✓ |
|---|---|---|---|
| 1 | Entrar como coleccionista y abrir un sobre de FA01 | Al voltear cada carta, se ve viva: se inclina al arrastrar el dedo, con partículas y el sello saltando; va fluida, sin tirones | |
| 2 | Dejar la carta quieta en el centro | Se balancea suave sola | |
| 3 | Terminar el sobre | En la bandeja y el resumen, las cartas se ven como imagen fija, iguales a la viva quieta | |
| 4 | Mi colección → FA01 → tocar una carta | La ficha muestra la carta viva | |
| 5 | Activar «Mover con el teléfono» (en iPhone, aceptar el permiso) | La carta sigue la inclinación del teléfono; al apagarlo, vuelve a seguir el dedo | |
| 6 | En iPhone, repetir el 5 negando el permiso (o en Ajustes de Safari) | El interruptor se apaga solo y avisa que la carta se inclina con el dedo | |
| 7 | Una carta holo (si hay) | Brillo arcoíris encima, en la viva y en la miniatura | |
| 8 | Activar «Reducir movimiento» del teléfono y abrir la ficha | Se ve la imagen fija, sin animación | |
