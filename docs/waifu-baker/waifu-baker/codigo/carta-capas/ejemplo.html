Para tu equipo

Todo sale de un solo componente, carta-capas.js, sin dependencias. Cada carta se describe con sus capas, su marco de rareza y su sello. La ficha y la apertura usan exactamente el mismo código; la apertura solo oculta el sello y llama a entrar() al voltear la carta.

const carta = CartaCapas.montar(contenedor, {
  marco: 'ssr',
  capas: [
    { src: 'yuki_1_fondo.webp',       profundidad: 0.2,  margen: 5 },
    { destellos: true,                profundidad: 0.55, margen: 4 },
    { src: 'yuki_3_personaje.webp',   profundidad: 1 },
    { src: 'yuki_4_particulas1.webp', profundidad: 1.3,  margen: 6, mezcla: 'overlay' },
    { src: 'yuki_5_insignia.webp',    profundidad: 1.6 }
  ],
  sello: { src: 'yuki_ssr.webp', esquina: 'sup-izq' }
});

carta.set({ holo: true });   // versión holo
carta.ocultarSello();        // antes de revelar
carta.entrar();              // al voltear: el SSR rebota y pasa un destello
