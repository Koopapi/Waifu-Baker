# Estilo visual · Waifu Baker

Hay dos direcciones propuestas. Las pantallas de cada una están en `../disenos/` (`a-*.html` y `b-*.html`) y los colores como variables CSS en `../tokens/`.

## A · Pop pastel (oscuro)

Nocturno y suave. Funciona muy bien para la apertura de sobres.

| Token | Color | Uso |
|---|---|---|
| Tinta | `#0F0C14` | Fondo |
| Superficie | `#1A1622` | Tarjetas |
| Línea | `#3A3147` | Bordes |
| Texto | `#FFF7FB` / `#CFC6DA` | Texto principal / secundario |
| Chicle | `#FF6FB8` | Acción principal |
| Menta | `#A6F0E6` | Enlaces, rareza R |
| Limón | `#FFE66B` | Galletas, sombras de botones |
| Lavanda | `#C8A8FF` | Rareza SR |
| Lima | `#86F07C` | Éxito (poco) |
| Durazno | `#FFC7A6` | Degradados |
| Holográfico | `#FF9AD5 → #FFC7A6 → #FFE66B → #A6F0E6 → #C8A8FF` | Solo SSR, progreso y momentos especiales |

**Tipografía:** Lilita One (títulos) · M PLUS Rounded 1c (texto, incluye japonés) · Unbounded (etiquetas en mayúsculas).

**Reglas:** el fondo siempre es tinta. Un solo botón chicle por pantalla. El holográfico solo para lo especial.

## B · Street pop (claro) · elegida

Energía de promo de juego gacha. La ficha de carta sirve casi tal cual como póster de "nueva carta" para X.

| Token | Color | Uso |
|---|---|---|
| Lila | `#ECE4FA` | Fondo |
| Tinta | `#17132B` | Texto, bordes y sombras |
| Índigo | `#3B2FC9` | Franjas, rareza SR |
| Blanco | `#FFFFFF` | Tarjetas |
| Neón rosa | `#FF3EA5` | Acción principal |
| Lima | `#C6F432` | SSR y destacados |
| Turquesa | `#3FE0D0` | Rareza R, acentos |
| Trama amarilla | `#FFD93D` | Solo decoración (puntos de semitono) |

**Tipografía:** Dela Gothic One (títulos, incluye japonés) · Archivo (itálica gruesa en mayúsculas para botones y etiquetas; normal para texto).

**Reglas:** bordes de tinta de 3 px y sombras duras sin difuminar. Etiquetas inclinadas, textos largos no. El rosa neón y la lima nunca como texto sobre el lila; úsalos de fondo con texto de tinta.
